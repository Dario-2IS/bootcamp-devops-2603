# Tarea de Python

Ejemplo de conceptos básicos de Python para el bootcamp DevOps.

## Contenido

- Variables.
- Condicionales y bucles.
- Listas y diccionarios.
- Funciones y manejo de errores.
- Lectura y escritura de archivos.
- Entorno virtual y archivo .gitignore.

## Cómo ejecutar el programa

Desde la carpeta luisramirez/python, crea y activa el entorno virtual:

    python3 -m venv .venv
    source .venv/bin/activate

Ejecuta el programa:

    python archivo1.py

El programa crea y lee el archivo resultado.txt. Este archivo y el entorno virtual no se suben al repositorio porque están incluidos en .gitignore.

Para salir del entorno virtual:

    deactivate
