## Monitor.sh 
Este script está escrito en Bash y su objetivo es monitorear el rendimiento de un sistema Linux, revisando tres métricas principales:

-Uso del CPU.
-Uso de la memoria RAM.
-Uso del espacio en disco.

Si cualquiera de estas métricas supera el 80%, muestra una alerta.

## readAndPrint
Este script está escrito en Bash y su función principal es leer una línea de texto desde la entrada estándar (stdin), almacenarla en una variable y después mostrarla en pantalla.

#####
Para utilizar cualquiera de los scripts en esta carpeta asegurate de cambiar los permisos para hacerlo ejecutable una vez descargado 
Utiliza chmod +x 'nombre del archivo', i.e "chmod +x monitor.sh"
